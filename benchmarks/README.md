# Benchmarks

Public benchmark evidence for the current Trust Agent system.

## Available benchmarks

| Benchmark | Status | Summary |
|---|---|---|
| [Current Validation v1](current-validation-v1/) | Complete | 10 adversarial cases + 10 benign controls, with precommitted expected outcomes |
| [OWASP Agentic Top 10](owasp-agentic-top10/) | Active benchmark family | Incident-derived OWASP Agentic Top 10 challenge suites. v1 contains 10 previously unseen cases, one per ASI01–ASI10 category, with frozen expected outcomes and public results |

The detailed methodology, results, mismatches, source provenance, and scope boundaries are documented inside each benchmark folder.

OWASP benchmark versions are frozen after their first execution. Newly discovered OWASP-relevant cases are added in later versions rather than modifying previously observed suites.
